## 😡 What Users HATE & Pet Peeves (The Landmines to Avoid)

### Pet Peeve #1: **Discussion Board Redesign** (Canvas 2024 - MAJOR BACKLASH!)

**The Problem:**

Canvas redesigned discussion boards in 2024. **Users HATE it.**

**Specific Complaints:**

> "I truly HATE the new design. Makes me want to leave Canvas." - Instructor

> "Can't see replies without clicking each post. Discourages engagement." - Student

> "Requires hitting 'expand threads' every single time. Exhausting." - Teacher

**What They Changed:**
- Old: Threaded view, see all replies at once
- New: Collapsed replies, must expand each thread manually
- Old: Easy to follow conversations
- New: Excessive navigation required

**User Impact:**
- Students find participation too time-consuming
- Teachers struggle to see class engagement
- Completion of discussion assignments dropped

**Canvas's Mistake:**
- Changed something that worked fine
- Didn't test with users first
- Ignored feedback when users complained

**Our Lesson:**
✅ **NEVER redesign working features without user testing!**
✅ If you must redesign, make it optional (old view + new view toggle)
✅ Listen when users complain

---
