# PowerHaus Academy Branding

## Logo Specifications

### Main Logo
- **File:** `powerhaus-logo.png`
- **Size:** 500x200px (or similar 2.5:1 ratio)
- **Format:** PNG with transparent background
- **Usage:** Navigation bar, header, marketing materials

### Logo Variants
- **White Logo:** `powerhaus-logo-white.png` (for dark backgrounds)
- **Icon Only:** `powerhaus-icon.png` (200x200px square)

### Favicon
- **File:** `favicon.ico` or `favicon.png`
- **Size:** 32x32px or 64x64px
- **Format:** ICO or PNG
- **Usage:** Browser tab icon

## Brand Colors

- **Primary Purple:** `#B266FF` (Electric Purple)
- **Secondary Cyan:** `#00FFA3` (Electric Cyan)
- **Background:** `#000000` (Pure Black - OLED optimized)
- **Text:** `#E5E5E5` (Silver - easy on eyes)

## How to Upload

1. Place your logo files in this `/public/branding/` folder
2. The app will automatically detect and use them
3. Access via admin panel at `/branding` to customize further
